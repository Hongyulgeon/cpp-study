# 프로그래밍 언어 (2026 2학기, 화78·목78)

수업 시간에 작성한 C++ 코드를 날짜별로 정리했습니다. 노션 「프로그래밍 언어 자료」 필기에서 옮겨 왔습니다.

## 실행 방법

모든 예제는 수업 템플릿대로 `save("소스.cpp")`를 호출합니다.
`common/save.h`, `common/save.cpp`를 함께 프로젝트에 넣고, 예제 파일 하나를 `소스.cpp`로 두고 빌드하면 됩니다.
(Visual Studio, C++23 `/std:c++latest` — `<print>` 사용)
